# Data (not included)
The CWRU `.mat` files are not stored in this repository (size and licence). The notebook downloads them automatically.
If the CWRU server is blocked, put the 12 kHz drive-end files in a folder as `97.mat` ... `237.mat` and set `CWRU_DIR`.
Files used: normal 97-100; faults IR 105-108, 169-172, 209-212; B 118-121, 185-188, 222-225; OR@6 130-133, 197-200, 234-237.
Source: Case Western Reserve University Bearing Data Center, https://engineering.case.edu/bearingdatacenter
Our results run used a public GitHub mirror of the same files (s-whynot/CWRU-dataset) because the CWRU site was unreachable.
